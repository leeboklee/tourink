# Tourink

Korea travel feed for foreigners — Instagram-style discovery, plus routes, hotels, nightlife, community, forum, and Klook-like experiences.

## Stack

- Next.js 15 (App Router)
- TypeScript + Tailwind CSS
- Mock data MVP (no DB required)

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy

Connect the GitHub repo to Vercel. Build command: `npm run build`.
